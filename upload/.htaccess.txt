# 1. Для використання URL Псевдонімів потрібно запустити apache з увімкненим mod_rewrite.

# 2. У вашій директорії opencart перейменуйте htaccess.txt на .htaccess.

# З будь-якими питаннями підтримки звертайтесь: http://www.opencart.com

Options +SymlinksIfOwnerMatch

# Запобігання перегляду вмісту директорії
Options -Indexes

# Запобігання прямого доступу до файлів
<FilesMatch "(?i)((\.tpl|\.twig|\.ini|\.log|(?<!robots)\.txt))">
 Require all denied
## Для apache 2.2 та старіших версій, замініть "Require all denied" на ці два рядки:
# Order deny,allow
# Deny from all
</FilesMatch>

# Налаштування SEO URL
RewriteEngine On
# Якщо ваша установка opencart не працює в головній веб-папці, переконайтеся, що наступне встановлено в папку, в якій вона працює, тобто / стає /shop/
RewriteBase /
RewriteCond %{QUERY_STRING} ^(.*)&?page=1$
RewriteRule ^(.*)/?$ /$1?%1%2 [R=301,L] #видалити page=1 з url
RewriteRule ^sitemap.xml$ index.php?route=extension/feed/google_sitemap [L]
RewriteRule ^googlebase.xml$ index.php?route=extension/feed/google_base [L]
RewriteRule ^system/storage/(.*) index.php?route=error/not_found [L]
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteCond %{REQUEST_URI} !.*\.(ico|gif|jpg|jpeg|png|webp|js|css)
RewriteRule ^([^?]*) index.php?_route_=$1 [L,QSA]

### Додаткові налаштування, які можуть потребувати увімкнення для деяких серверів
### Розкоментуйте команди, видаливши знак # перед ними.
### Якщо ви отримаєте "Internal Server Error 500" після увімкнення будь-якого з наступних налаштувань, відновіть #, оскільки це означає, що ваш хостинг не дозволяє це.

# 1. Встановити максимальний розмір файлу для завантаження. Більшість хостингів обмежують це і не дозволяють перевизначати, але ви можете спробувати.
# php_value upload_max_filesize 999M

# 2. Встановити максимальний розмір POST. Розкоментуйте цей рядок, якщо у вас багато опцій товарів або ви отримуєте помилки, коли форми не зберігають всі поля.
# php_value post_max_size 999M

# 3. Встановити максимальний час виконання скрипта. Розкоментуйте цей рядок, якщо у вас багато опцій товарів або ви отримуєте помилки, коли форми не зберігають всі поля.
# php_value max_execution_time 200

# 4. Встановити максимальний час для отримання вводу. Розкоментуйте цей рядок, якщо у вас багато опцій товарів або ви отримуєте помилки, коли форми не зберігають всі поля.
